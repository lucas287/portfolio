Voinich Motors

03 / FERRAMENTA DE MERCADO↗

Vestra

Problema

Pequenos comerciantes podem ter dificuldade para pesquisar produtos, comparar preços e planejar estratégias de venda.

O que eu fiz

Criei uma plataforma demonstrativa que reúne recursos de pesquisa de mercado, comparação de preços e apoio à tomada de decisão comercial.

Como eu fiz

Desenvolvi a interface com React, TypeScript e Vite, organizando telas e recursos de consulta e visualização.

Resultado

Uma demonstração web publicada para navegação. Os dados de preços, fornecedores e indicadores apresentados são ilustrativos, não cotações ou resultados comerciais reais.

04 / ASSISTENTE PESSOAL↗
Em desenvolvimento

UTRON — Assistente pessoal

Problema

Centralizar a interação com o computador e facilitar o acesso a recursos do Windows por comandos.

O que eu fiz

Estou desenvolvendo um assistente pessoal para Windows com interface própria, interação por texto e voz e integração com inteligência artificial.

Como eu fiz

O projeto utiliza Python e FastAPI no backend, Electron e TypeScript na aplicação desktop, Three.js na interface visual e SQLite para persistência de dados.

Resultado

Projeto em desenvolvimento, atualmente na versão 18, com código organizado em repositório público para acompanhar sua evolução.

PythonFastAPIElectronTypeScriptThree.jsSQLite
